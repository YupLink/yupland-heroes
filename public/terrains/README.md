# Типы местности (терайны) для карты рейда

11 тайлов местности в стиле «Герои Меча и Магии 3» — исходники для сборки карты
рейда. Формат PNG 295×295 (оригиналы, оставлены как есть — источник/бэкап).

Карта рейда (`/raid-hexmap`) грузит **`.webp`-версии** тех же 11 файлов
(добавлены рядом, `01_water.webp` и т.д. — конвертация `sharp`, quality 78):
~1.9 МБ суммарно в PNG превратились в ~320 КБ в WebP, визуально без потерь
(текстуры, артефактов сжатия почти не видно). Если понадобится перегенерить
после замены исходников — `sharp(png).webp({ quality: 78 })` на каждый файл.

Раздаются статикой: `https://service.yupland.io/terrains/<файл>`
(в деве Vite отдаёт `public/` по корню).

IPFS-зеркало (Pinata, тот же гейтвей, что у NFT-фишек):
`https://gateway.dialog-tbot.com/ipfs/QmaJo3pU9RcsL6kmkAVR2kBzYiPb1Da1T5hDPQiDEhhh56/<файл>`
